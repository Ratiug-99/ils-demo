# ILS draft: click-through copy

A clickable copy of an early draft (v0) of an ILS data system: configuration register, failure and hazard sheet,
repair options, task library, provisioning pack, and the VisBo helper.

- All data is invented sample data.
- Saving is off: forms and uploads show what would happen, nothing is stored.
- Pages are marked noindex (kept out of search engines).

Open: https://ratiug-99.github.io/ils-demo/
